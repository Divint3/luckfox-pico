## 2026-09-26 CI 缓存故障复盘
- CI 报 "No rule to make target 'luckfox_pico_defconfig'"（buildroot 阶段）。
- 根因：我设计的缓存路径 buildroot-2023.02.6/dl，actions/cache 恢复时创建父目录 → sysdrv 的 test -d 惰性初始化误判 → 解压+defconfig 拷贝被跳过。
- 教训：缓存子路径不能触发宿主脚本的"目录存在即初始化完成"判断；应缓存整个 buildroot 目录，key 绑定 sysdrv/tools/board/buildroot/** 哈希，不用 restore-keys 防旧树污染。
- 已修复 build.yml（Cache buildroot tree）。luckfox_pico_defconfig 是 buildroot 的 defconfig（sysdrv/tools/board/buildroot/ 下预置），非内核 defconfig。
